<CardGrid>
	<Card title="插件接入，无需改动智能体" icon="puzzle">
		HALO 是一个 MCP 服务器。能接入自定义 MCP 服务器的宿主（即运行智能体的应用），例如 ChatGPT dots、Grok Bot、Claude Code 和 Codex，不改自己的代码就能使用它。[如何接入](/HALO/zh-cn/architecture/)。
	</Card>
	<Card title="从引用读出通路" icon="random">
		智能体记录的每一步都写明它用到了哪些更早的步骤。一个记忆步骤被一个行动步骤用到，就是通路 M→A。[事件模型](/HALO/zh-cn/architecture/events/)。
	</Card>
	<Card title="自我改进的证据" icon="list-format">
		HALO 从一次行动出发，依次追踪它的结果、这个结果引出的修订，以及之后用到这次修订的行动。[分析](/HALO/zh-cn/architecture/analysis/)。
	</Card>
	<Card title="等级是下界" icon="approve-check">
		报告把轨迹放到 L0 到 L5 中的某个闭环等级上，实际等级可能更高。报告还会说明到达下一级需要什么。[等级](/HALO/zh-cn/concepts/levels/)。
	</Card>
</CardGrid>
