<CardGrid>
	<Card title="A plugin, not a fork" icon="puzzle">
		HALO is an MCP server. Hosts that take a custom MCP server, such as ChatGPT dots, Grok Bot, Claude Code, and Codex, can use it without changing their code. [How it connects](/HALO/architecture/).
	</Card>
	<Card title="Channels from links" icon="random">
		Every step the agent logs names the earlier steps it used. A Memory step used by an Action step is the channel M→A. [Event model](/HALO/architecture/events/).
	</Card>
	<Card title="Evidence for self-improvement" icon="list-format">
		HALO follows an action to its outcome, the revision the outcome led to, and the later action that used the revision. [Analysis](/HALO/architecture/analysis/).
	</Card>
	<Card title="Levels as lower bounds" icon="approve-check">
		The report places the trace at a loop-closure level from L0 to L5, and says what the next level would need. [Levels](/HALO/concepts/levels/).
	</Card>
</CardGrid>
