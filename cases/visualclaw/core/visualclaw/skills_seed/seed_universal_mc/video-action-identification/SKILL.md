## Identify Core Video Action vs. Secondary Details

1. Watch the video mentally and identify the MAIN activity (e.g., painting, pruning, playing cards).
2. For each option, separate:
   - **Core process**: The central repeated action
   - **Secondary details**: One-time interactions, posture changes, or peripheral activities
3. Select the option that captures the core process WITHOUT excessive secondary details.
4. Reject options that add deviations or tangential actions (e.g., "interacts with a boy and stands up from a chair").
5. Reject options that misidentify the activity (e.g., "harvesting" when the action is "pruning").

**Example:** If the video shows someone pruning plants, reject "harvesting" or "watering" even if those words appear plausible. Reject descriptions that add "also interacts with a boy" unless that's the core activity.

**Anti-pattern:** Selecting an option just because it contains some correct details mixed with incorrect secondary actions. Always prioritize accuracy of the PRIMARY action.
